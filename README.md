## 📝 Descripción del Proyecto

Entender qué variables climáticas afecta, y en qué medida, de manera directa al ganado lechero y a su entorno. Determinar que relación tienen estas variables y qué implicaciones tienen a mediano y largo plazo en la producción lechera en Machachi.
---

## ⚙️ Instrucciones de Instalación y Ejecución

### Requisitos
- Python 3.11+
- Librerías: incluidas en requirements.txt
- VS Code con la extensión de Jupyter

---

### 🪜 Pasos de Ejecución

1. Clonar el repositorio o ubicarte en la carpeta del proyecto:
   ```bash
   git clone https://github.com/fundestpuente/SIC26-Analisis-datos-climaticos-y-su-impacto-en-el-ganado-lechero-.git

   cd estres-termico-ganado-machachi
   ```

2. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
      ```

3. Abrir el notebook principal:
   ```bash
   jupyter notebook main.ipynb
      ```
   o directamente desde VS Code con la extensión de Jupyter.
